# AI시대의 보고서 리터러시 · 프롬프트

『AI시대의 보고서 리터러시』 교안(본편 12화 + 실전 Tip 10개)의 프롬프트를 골라 쓰는 웹 페이지입니다.
왼쪽 목차에서 프롬프트를 고르고, 점선 박스(빈칸)를 채운 뒤 **복사** 버튼으로 AI 대화창에 붙여 넣으세요.

## 실행 방법

```bash
git clone https://github.com/iksangyoo-sys/yes_prom.git
cd yes_prom
python3 -m http.server 8000
```

브라우저에서 <http://127.0.0.1:8000/> 을 엽니다. (`index.html`을 더블클릭해 바로 열어도 동작합니다.)

## 사용법

- **점선 박스** — 직접 채우는 칸입니다. 클릭해서 입력하면 이 브라우저에 자동 저장됩니다.
- **노란 대괄호** (`[확인 필요]`, `[추정]` 등) — AI가 답에 붙이는 표시이니 그대로 두세요.
- **복사** — 채운 내용을 합쳐 프롬프트 전체를 복사합니다. 비워 둔 칸은 `[대괄호]` 그대로 복사됩니다.
- 새 대화를 열면 제1화의 **기본정보 블록**을 먼저 보내고 각 프롬프트를 이어서 보내세요.
- **프롬프트 1/2 · 2/2**(실전10 이메일)는 이어 붙여 한 번에 보냅니다. `1/2+2/2 합쳐 복사` 버튼을 쓰세요.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 (사이드바 목차, 프롬프트 카드, 복사 기능) |
| `prompts.js` | 교안(`261025_프롬프트만(HTML작성용).pptx`)에서 뽑은 프롬프트 데이터 (본편 12화 + 실전 10개, 94개 프롬프트 + 기본정보 블록) |
| `tools/build_data.py` | PPTX 교안에서 `prompts.js`를 다시 만드는 스크립트 |

교안 PPTX를 고쳤다면 다음 명령으로 데이터를 다시 만듭니다 (`pip install python-pptx` 필요).

```bash
python3 tools/build_data.py 교안.pptx prompts.js
```
